# 更新日志

版本号规则：`versionName` = 主版本.次版本，`versionCode` = 主版本 × 10 + 次版本
（1.1 → 11，1.2 → 12，2.0 → 20）。

查当前版本：手机「设置 → 应用 → 桌宠遥控」，或

```powershell
aapt dump badging DeskPetRemote.apk | Select-String versionName
```

## 1.1 — 2026-10-27

界面重做 + 换配色。**指令协议一条都没改**，之前配的固件继续能用。

### 界面重做

- 从「一堆同款小方块」改成**五张分区卡片**：状态 / 移动 / 动作 / 灯光与显示 / 调速与天气
- **状态和动态动作彻底分开**：
  - 状态（放松趴下、蹲下、直立、趴下）发一次就保持，做成一排等宽档位
  - 动作（摇摆、摇尾巴、前跳…）有始有终，做完自己回待机，单独一区
- **前后左右改成十字方向键**，中间新增「站定」（复用 `0x31` 直立），
  想让它停不用再往上滚去找「直立」
- 方向键的箭头和文字分开缩放（箭头 1.55 倍、文字 0.78 倍），一眼看清朝哪
- 顶部标题栏也包成卡片，连接指示灯 + 扫描/断开按钮留在同一行
- 按过的按钮保持高亮（分类色描边加粗），断开连接时自动熄灭

### 配色换成「薄荷曼波」

| 色值 | 用途 |
| --- | --- |
| `#F9F4EA` 奶白 | 窗口背景 |
| `#CFE4DD` 薄荷 | 状态区 |
| `#FCD3D5` 樱花粉 | 动作区 |
| `#8D6C63` 摩卡棕 | 主色 / 文字 / 站定按钮 |
| `#EFDFCF` 奶油沙 | 灯光区（棕 + 奶白调和） |
| `#DCE7E0` 鼠尾草 | 调速区（薄荷 + 奶白调和） |

- 深色主题 → **浅色主题**（`Theme.Material.Light`），新增 `styles.xml`
  把状态栏、导航栏刷成奶白，避免顶上留一条黑边
- 按钮从「半透明叠色」改成**分类色实心填充** —— 浅色底上半透明会把颜色糊掉，
  实心才立得住；文字统一深棕 `#6B4F47`
- 卡片圆角 14 → 18dp，卡片描边改用 `#EDE3D6`

### 其他

- 按钮样式改成 `PetButton`（记住自己的分类色 + 样式），恢复高亮时按样式重建背景，
  不再依赖 `setTag` 存颜色 —— 因为十字盘方向键要用专门的「奶白底 + 浅棕描边」样式

### 协议

不变：一次点击 = 一个 ASCII 字节，无 CRLF。`0x52~0x55`（摇摆 26/27/16/15 秒）
仍然只走语音通道，App 上没有按钮。

### 配套固件

如果你遇到「连上蓝牙自己摇摆」或「切到别的动作表情还停在天气」，那是**固件**的问题
（蓝牙模块在连接/断开时会吐 `CONNECTED` / `DISCONNECTED` 状态串，里面的
`S`/`T` 正好撞上摇摆 27/16 秒），需要用修复后的固件（仓库提交 `3add183`）。
App 侧不需要跟着改。

## 1.0 — 2026-10-26

首个版本。

### 功能

- **BLE 扫描直连**：点扫描列出附近设备（名称 + 信号 + MAC），点一下就连上，
  不需要去系统蓝牙里配对
- **24 个按钮 / 23 个指令码**：状态 4、移动 4、动作 7、灯光与显示 5、调速与天气 4
- **天气**：定位 → Open-Meteo 取当天温度区间和湿度 → 蓝牙下发
  `AA 55 04 CODE TMIN TMAX HUM XOR` → 桌宠屏幕上显示「晴 24~29C 湿度60%」
- **语音说「天气」自动同步**：桌宠经蓝牙反向发一个 `0x57` 请求，App 收到后
  自动定位取天气、再把帧写回去，全程不用碰手机
- **发送记录**：时间戳 + 指令名 + 字符 + 十六进制，写失败会标 `×`
- 连接状态指示灯：灰（未连接）/ 琥珀（扫描、连接中）/ 绿（已就绪）

### 已知问题（当时未发现）

- 连接/断开蓝牙时桌宠会自己摇 16~27 秒 —— 固件侧原因，见 1.1 的「配套固件」
- 动作执行期间表情不刷新（动作是阻塞式的，把 30ms 的表情任务饿死了）——
  固件侧原因，同样已在 `3add183` 修复
