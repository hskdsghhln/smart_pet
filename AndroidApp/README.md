# 桌宠遥控（Android 蓝牙上位机）

通过手机蓝牙控制 STM32 桌面宠物的动作。对应固件 `HardWare/PetAction.c` 里的蓝牙指令表。

- 包名：`com.desktoppet.remote`
- 最低系统：Android 5.0（API 21）
- 传输：经典蓝牙 SPP 串口透传（HC-05 / HC-06）
- 协议：**每按一次按钮发送 1 个 ASCII 字节**，不加换行、不加回车

安装包：`DeskPetRemote.apk`（约 29 KB）

---

## 一、安装

把 `DeskPetRemote.apk` 传到手机（微信文件传输 / 数据线 / 网盘都行），点击安装。
首次安装需要在系统里允许"安装未知来源应用"。

## 二、第一次使用先配对

App 只连接**已配对**的设备，配对这一步要走系统蓝牙：

1. 给桌宠上电，蓝牙模块开始闪灯
2. 手机 → 设置 → 蓝牙 → 打开 → 扫描 → 找到 `HC-05` 或 `HC-06`
3. 点它配对，密码一般是 `1234` 或 `0000`
4. 打开 App → 点右上角 **连接** → 在弹出的列表里选设备
5. 左上角状态灯变绿、显示"已连接"就成功了

> 如果没有配对过，App 会提示并给你一个「打开蓝牙设置」的按钮。

## 三、界面说明

按钮分 5 组，底部是发送记录（时间戳 + 指令名 + 实际字节 + 十六进制），
可以用来确认 App 发的字节和固件里的一致。

| 分组 | 按钮 |
| --- | --- |
| 姿态 | 放松趴下、蹲下、直立、趴下 |
| 移动 | 前进、后退、左转、右转、摇摆 |
| 特技 | 前跳、后跳、打招呼、伸懒腰、拉伸、摇尾巴 |
| 灯光与状态 | 开灯、关灯、呼吸灯开、呼吸灯关、显示电量 |
| 调速 | 走路加速、摇摆加速 |

## 五、几个容易踩的点

- **移动类指令是持续的**：按了"前进"它就一直走，直到你按别的（比如"直立"）。
  这是固件里蓝牙通道 `Sustainedmove=1` 的设计，不是 App 的 bug。
- **摇尾巴 / 显示电量 是开关**，按一次开、再按一次关。
- **调速是循环的**，按到最快再按会回到最慢。
- 发送记录里的十六进制可以拿来和固件 `case 0x??` 对照，排查问题很方便。
- 手机和蓝牙模块的有效距离通常 10 米以内，中间隔墙会掉。

## 六、重新编译

```powershell
cd AndroidApp
powershell -ExecutionPolicy Bypass -File build_apk.ps1
```

脚本不依赖 Gradle / Android Studio，直接用 SDK 里的 `aapt` + `d8` + `apksigner` 打包。
会自动搜索以下工具，找不到会报错说明缺什么：

| 用途 | 需要 |
| --- | --- |
| 编译 Java | 带 `javac` 的 JDK 8 |
| 打 dex / 签名 | Java 11 及以上的运行时 |
| 资源 / 对齐 | Android SDK `build-tools` |
| 框架 | Android SDK `platforms/android-35` |

本机自动匹配到的是：

- JDK 8：`C:\Program Files\Android\jdk\jdk-8.0.302.8-hotspot\jdk8u302-b08`
- JRE 17：`%LOCALAPPDATA%\Android\jre17\jdk-17.0.20.1+1-jre`
- SDK：`%LOCALAPPDATA%\Android\Sdk`

> 注意：`build_apk.ps1` 开头带 UTF-8 BOM。如果编辑后 BOM 丢了，
> PowerShell 5.1 会按 ANSI 解码，中文注释可能把语法搞坏。

## 八、改指令表

所有按钮都在 `MainActivity.java` 顶部：

```java
private static final Cmd[][] GROUPS = {
    { new Cmd("放松趴下", ')'), ... },
    ...
};
```

加一个按钮就是在对应数组里加一行 `new Cmd("名字", '指令字符')`，
按钮会自动排版（每行 4 个，最后一行自动补齐）。前提是固件里
`Command_IsValid()` 白名单允许这个字节，否则会被固件丢掉。
